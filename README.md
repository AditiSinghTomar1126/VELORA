# VELORA — Salon

React + TypeScript + Vite + Tailwind CSS v4 starter.

## Pages
- /
- /services
- /contact
- /gallery
- /about

## Components
Navbar, Hero, About, Services, Packages, Gallery, Team, BookingCTA, Contact, Footer, Button, SectionHeading, FloatingPetals.

## Run
npm install
npm run dev

## Assets
The UI references images under `public/images/`. Placeholder filenames are documented in `public/images/README.md`.
Replace them with your final photography later; the layout/data architecture does not need to change.
